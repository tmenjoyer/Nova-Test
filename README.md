# NOVA — FULL PROJECT

## Lancer le site
1. Décompresse `NOVA_FULL_PROJECT.zip`.
2. Ouvre `index.html` dans Chrome, Edge ou Firefox.
3. Aucun serveur n'est nécessaire pour les fonctions principales.

## Fonctionnalités
- Navigation fluide + menu mobile
- Mode sombre / clair sauvegardé
- Recherche globale et recherche de projets
- Filtres IA / Web / XR
- Fiches projets avec modales
- Idée aléatoire
- Compteurs animés
- Formulaire de contact avec validation et sauvegarde locale
- Boutons et interactions avec notifications
- Interface responsive
- Animations au scroll
- Effets visuels CSS
- Aucun backend requis

## Personnalisation
- `index.html` : textes, projets et structure
- `style.css` : design, couleurs, responsive
- `script.js` : interactions et logique

Le formulaire est actuellement une démo front-end : il ne transmet pas réellement un email à un serveur.
